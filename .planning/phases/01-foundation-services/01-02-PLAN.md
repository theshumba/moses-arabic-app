**Step 2: Create src/data/cardGenerator.js**

Import all data sources and generate cards per deck. EVERY card must have this shape:

```js
{
  id: string,           // Unique across all decks
  deckId: string,       // Matches DECKS[].id
  front: {
    primary: string,    // Main display (often English or prompt)
    secondary?: string, // Optional subtitle
    hint?: string,      // Optional hint text
  },
  back: {
    primary: string,    // Main answer (often Arabic)
    secondary?: string, // Optional detail (transliteration)
    detail?: string,    // Optional extra info
  },
  typeAnswer: {
    prompt: string,     // What to type
    acceptedAnswers: string[], // Valid answers (normalized comparison)
  },
}
```

Generator functions (one per deck type):
- `generateLetterRecognition(alphabet)` — 28 cards (skip hamza/taa marbuta special entries if present, use only the 28 standard letters). Front: name + transliteration. Back: isolated Arabic letter.
- `generateLetterForms(alphabet)` — 28 x 4 = 112 cards. Front: letter name + position (initial/medial/final/isolated). Back: correct form.
- `generateHarakat(alphabet)` — 28 letters x 7 diacritics (fatha, kasra, damma, sukun, shadda, tanwin fatha, tanwin kasra). Use vowelCombinations from alphabet.json where available; generate remaining programmatically. Target ~196 cards but actual count depends on data — the alphabet.json has 3 vowelCombinations per letter, so generate the remaining 4 diacritics per letter programmatically.
- `generateSunMoon(alphabet)` — 28 cards. Sun letters: ت ث د ذ ر ز س ش ص ض ط ظ ل ن. Moon letters: the rest. Front: letter. Back: sun/moon + ال rule.
- `generateNumbers(numberCards)` — 10 cards from numberCards.js.
- `generateUniVocab(uniVocab)` — ~90 cards from uniVocab.js. Front: English. Back: Arabic + transliteration.
- `generateGrammar(grammarCards)` — ~80 cards from grammarCards.js. Front: grammar prompt. Back: Arabic answer.
- `generateCommonWords(vocabulary)` — 250 cards from vocabulary.json. Front: English + category. Back: Arabic + transliteration.
- `generateConnectedReading(readingCards)` — ~50 cards. Front: Arabic word. Back: letter breakdown + English.
- `generateReadingPractice(readingCards)` — ~30 cards. Front: Arabic sentence. Back: English + transliteration.

Export `generateAllCards()` which returns a Map<deckId, Card[]> and `getAllCardsFlat()` which returns Card[].

**Step 3: Create src/data/index.js** (barrel export)

```js
import { DECKS, STAGES } from './decks.js'
import { generateAllCards, getAllCardsFlat } from './cardGenerator.js'

const CARD_MAP = generateAllCards()
const ALL_CARDS = getAllCardsFlat()

export { DECKS, STAGES, CARD_MAP, ALL_CARDS }

export function getCardsByDeck(deckId) {
  return CARD_MAP.get(deckId) || []
}

export function getCardById(cardId) {
  return ALL_CARDS.find(c => c.id === cardId)
}
```
