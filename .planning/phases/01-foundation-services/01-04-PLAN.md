Create `src/services/DeckService.js` — pure functions for deck unlock logic, stats computation, and mastery calculation.

**API:**

```js
import { DECKS, STAGES } from '../data/decks.js'
import { SrsService } from './SrsService.js'

export const DeckService = {
  getDeckStats(deckId, allProgress, deckCardIds) {},
  isDeckUnlocked(deckId, allProgress, allCardsByDeck) {},
  getStageMastery(stageId, allProgress, allCardsByDeck) {},
  getUnlockRequirement(deckId) {},
  getAllDeckStats(allProgress, allCardsByDeck) {},
}
```

**getDeckStats(deckId, allProgress, deckCardIds):**
Returns:
```js
{
  total: number,      // Total cards in deck
  seen: number,       // Cards with totalReviews > 0
  mastered: number,   // Cards where isCardMastered() returns true
  due: number,        // Cards where isCardDue() returns true (now)
  new: number,        // Cards with no progress
  masteryPercent: number, // (mastered / total) * 100, rounded to 1 decimal
  seenPercent: number,    // (seen / total) * 100, rounded to 1 decimal
}
```

Params:
- `deckCardIds`: array of card IDs belonging to this deck (from getCardsByDeck)
- `allProgress`: object `{ [cardId]: progressObject }` from ProgressContext

**isDeckUnlocked(deckId, allProgress, allCardsByDeck):**
Returns boolean. Implements prerequisite chain from DECKS[].prerequisite.

Prerequisite evaluation:
- `prerequisite === null` → always unlocked (Deck 1: letter-recognition)
- `{ deckId, metric: 'seen', threshold: 0.8 }` → seenPercent of prerequisite deck >= 80%
- `{ deckId, metric: 'goodPlus', threshold: 0.6 }` → % of cards in prerequisite deck with lastRating >= 3 at least once >= 60%. (Use: cards where totalReviews > 0 AND lastRating >= 3)
- `{ deckId, metric: 'mastered', threshold: 0.7 }` → masteryPercent of prerequisite deck >= 70%
- `{ metric: 'stageMastery', stage: N, threshold: 0.5 }` → getStageMastery(stage) >= 50%

`allCardsByDeck` is an object `{ [deckId]: cardId[] }` — a pre-computed map.

**getStageMastery(stageId, allProgress, allCardsByDeck):**
Returns number 0-100 (percentage). Computed as: average of masteryPercent across all decks in the stage.

```js
const stageDecks = DECKS.filter(d => d.stage === stageId);
const totalMastery = stageDecks.reduce((sum, d) => {
  const stats = DeckService.getDeckStats(d.id, allProgress, allCardsByDeck[d.id] || []);
  return sum + stats.masteryPercent;
}, 0);
return totalMastery / stageDecks.length;
```

**getUnlockRequirement(deckId):**
Returns a human-readable string describing what's needed to unlock:
- "Always available" for null prerequisite
- "See 80% of Letter Recognition" for seen metric
- "Rate 60% of Letter Forms as Good or better" for goodPlus metric
- "Master 70% of Letter Forms" for mastered metric
- "Reach 50% mastery in Stage 1: The Script" for stageMastery metric

**getAllDeckStats(allProgress, allCardsByDeck):**
Returns array of `{ deck, stats, unlocked, unlockText }` for all 10 decks. Convenience method for Dashboard/DecksPage.

**IMPORTANT:**
- All functions are PURE. They receive data and return results. No side effects.
- DeckService imports DECKS from data layer but does NOT import StorageService.
- The unlock logic must handle the case where prerequisite deck has 0 cards gracefully (return unlocked to prevent deadlock).

Create `src/services/StatsService.js` — session time tracking and study streak calculation.

**API:**

```js
import { StorageService } from './StorageService.js'

export const StatsService = {
  // Session management
  startSession() {},
  endSession(cardsReviewed, ratingsBreakdown) {},

  // Queries (pure functions where possible)
  getTodayStats() {},
  getStreak() {},
  getAllTimeStats() {},
  getSessionHistory(limit) {},
}
```

**Storage keys (via StorageService):**
- `sessions`: Array of session records
- `streak`: `{ current: number, lastStudyDate: string (ISO date, date-only) }`

**startSession():**
Records session start time in module-level variable (NOT in localStorage — ephemeral).
Returns `{ startedAt: new Date().toISOString() }`.

**endSession(cardsReviewed, ratingsBreakdown):**
Computes duration from startSession timestamp. Creates session record:
```js
{
  date: new Date().toISOString(),
  duration: number,           // seconds
  cardsReviewed: number,
  ratings: { again: N, hard: N, good: N, easy: N },
  accuracy: number,           // % rated Good or Easy
}
```
Appends to `sessions` array in StorageService. Updates streak. Keep only last 100 sessions (prevent unbounded growth — Pitfall #5).

**getTodayStats():**
Filters sessions by today's date. Returns:
```js
{
  totalTime: number,       // seconds studied today
  cardsReviewed: number,   // total cards reviewed today
  sessions: number,        // number of sessions today
  accuracy: number,        // average accuracy today
}
```

**getStreak():**
Returns `{ current: number, lastStudyDate: string }`.

Streak logic:
- If last study date is today → streak is current value
- If last study date is yesterday → streak is current value (not broken yet)
- If last study date is older → streak resets to 0
- When endSession is called: if lastStudyDate !== today, increment streak and update lastStudyDate

Uses date-fns `startOfDay`, `differenceInCalendarDays` for date comparison.

**getAllTimeStats():**
Returns:
```js
{
  totalSessions: number,
  totalCards: number,
  totalTime: number,        // seconds
  averageAccuracy: number,  // % across all sessions
  averageCardsPerDay: number,
  startDate: string,        // first session date
}
```

**getSessionHistory(limit = 10):**
Returns the last N session records, most recent first.

**IMPORTANT:**
- StatsService is the ONLY service that uses StorageService for its own data.
- Session start time is ephemeral (module variable, not persisted).
- Limit stored sessions to 100 to prevent localStorage growth (Pitfall #5).
- Use date-fns for all date comparisons.
