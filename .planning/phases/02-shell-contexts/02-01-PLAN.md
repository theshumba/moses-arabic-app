  <action>
Create `src/contexts/` directory.

**ProgressContext.jsx:**
- Import `createContext`, `useContext`, `useEffect`, `useReducer`, `useRef` from React
- Import `StorageService` from `../services/StorageService.js`
- Create two contexts: `ProgressStateContext` and `ProgressDispatchContext` (both init `null`)
- `initialState = { cardProgress: {} }`
- Reducer actions:
  - `LOAD`: spread payload into state (`{ ...state, ...action.payload }`)
  - `REVIEW_CARD`: merge single card progress (`{ ...state, cardProgress: { ...state.cardProgress, [action.payload.cardId]: action.payload.progress } }`)
  - `CLEAR_ALL`: reset to `{ cardProgress: {} }`
  - Default: return state unchanged
- `ProgressProvider({ children })`:
  - `useReducer(progressReducer, initialState)`
  - `initialized = useRef(false)` guard for hydration race condition
  - **Mount effect** (`[]` deps): call `StorageService.get('progress')`, if truthy dispatch `{ type: 'LOAD', payload: { cardProgress: saved } }`, then set `initialized.current = true`
  - **Persist effect** (`[state.cardProgress]` dep): guard with `if (!initialized.current) return`, then call `StorageService.set('progress', state.cardProgress)`
  - **Beforeunload effect** (`[]` deps): add `beforeunload` listener calling `StorageService.flushAll()`, clean up on unmount
  - Render: `<ProgressStateContext value={state}><ProgressDispatchContext value={dispatch}>{children}</ProgressDispatchContext></ProgressStateContext>`
  - Use React 19 `<Context value={}>` syntax (NOT `<Context.Provider value={}>`)
- Export `ProgressProvider`, `useProgressState()` (throws if null), `useProgressDispatch()` (throws if null)

**SettingsContext.jsx:**
- Same split pattern as ProgressContext
- `DEFAULT_SETTINGS = { studyMode: 'flip', newCardsPerSession: 50 }`
- `initialState = { settings: { ...DEFAULT_SETTINGS } }`
- Reducer actions:
  - `LOAD`: merge loaded settings with defaults (`{ ...state, settings: { ...DEFAULT_SETTINGS, ...action.payload } }`)
  - `UPDATE_SETTINGS`: merge partial update (`{ ...state, settings: { ...state.settings, ...action.payload } }`)
  - Default: return state
- `SettingsProvider({ children })`:
  - Same `initialized` ref guard pattern
  - Mount effect: `StorageService.get('settings')`, dispatch LOAD if truthy, set initialized
  - Persist effect on `[state.settings]`: guard with initialized, call `StorageService.set('settings', state.settings)`
  - Beforeunload effect: same flushAll pattern
  - Render with React 19 `<Context value={}>` syntax
- Export `SettingsProvider`, `useSettingsState()`, `useSettingsDispatch()`
  </action>
