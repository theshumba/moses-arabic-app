Rewrite `src/pages/StudyPage.jsx` (currently a placeholder) to compose the full study experience.

**Imports:**
- `useParams, useNavigate, Link` from `react-router-dom`
- `useEffect, useMemo` from `react`
- `useStudySession` from `../hooks/useStudySession.js`
- `FlashCard` from `../components/study/FlashCard.jsx`
- `RatingButtons` from `../components/study/RatingButtons.jsx`
- `SessionComplete` from `../components/study/SessionComplete.jsx`
- `DeckService` from `../services/DeckService.js`
- `DECKS, getCardsByDeck` from `../data/index.js`
- `useProgressState` from `../contexts/ProgressContext.jsx`

**Route params and validation:**
1. `const { deckId } = useParams()`
2. `const navigate = useNavigate()`
3. Find deck: `const deck = DECKS.find(d => d.id === deckId)`
4. If no deckId or deck not found: render "Select a deck" message with link to `/decks`

**Deck lock check:**
1. `const { cardProgress } = useProgressState()`
2. Build allCardsByDeck (useMemo, same pattern as Sidebar):
   ```js
   const allCardsByDeck = useMemo(() => {
     const map = {};
     for (const d of DECKS) {
       map[d.id] = getCardsByDeck(d.id).map(c => c.id);
     }
     return map;
   }, []);
   ```
3. `const isUnlocked = DeckService.isDeckUnlocked(deckId, cardProgress, allCardsByDeck)`
4. If locked: render lock message with `DeckService.getUnlockRequirement(deckId)` and link back to `/decks`

**Study session (only if deckId valid AND unlocked):**
1. `const session = useStudySession(deckId)`
2. Destructure: `{ currentCard, isFlipped, isComplete, cardsCompleted, totalCards, flip, rate, sessionResult }`

**Keyboard shortcuts (useEffect):**
Register a `keydown` listener on `document`:
- Guard: if `document.activeElement` is an `INPUT`, `TEXTAREA`, or `SELECT`, return early (don't fire shortcuts in form fields)
- `Space` or `' '`: call `flip()` if not flipped and not complete. `e.preventDefault()` to prevent page scroll.
- `1`: call `rate(1)` if flipped and not complete
- `2`: call `rate(2)` if flipped and not complete
- `3`: call `rate(3)` if flipped and not complete
- `4`: call `rate(4)` if flipped and not complete
- `Escape`: `navigate('/decks')` — exit study to decks page
- Dependency array: `[isFlipped, isComplete, flip, rate, navigate]`
- Cleanup: remove event listener

**Rendering logic:**

1. **Session complete state** (`isComplete && sessionResult`):
   - Render `<SessionComplete sessionResult={sessionResult} deckId={deckId} deckName={deck.name} />`

2. **Active study state** (not complete, has currentCard):
   - Header row: deck name (`text-text-muted text-sm mb-2`) + progress indicator (`cardsCompleted + 1` / `totalCards` as `text-text-dim text-sm`)
   - `<FlashCard card={currentCard} isFlipped={isFlipped} onFlip={flip} />`
   - If flipped: `<RatingButtons onRate={rate} disabled={false} />` below the card with `mt-6`
   - If not flipped: subtle hint "Press Space or tap the card" in `text-text-dim text-xs text-center mt-6`

3. **Empty queue** (isComplete immediately, no sessionResult — queue was empty):
   - "No cards due" message
   - "All caught up! Come back later for reviews, or try another deck."
   - Link to `/decks`

**Progress bar:**
Above the card area, show a thin progress bar:
```jsx
<div className="h-1 rounded-full bg-surface-2 mb-6">
  <div
    className="h-1 rounded-full bg-accent transition-all duration-300"
    style={{ width: `${totalCards > 0 ? (cardsCompleted / totalCards) * 100 : 0}%` }}
  />
</div>
```

**Overall page structure:**
```jsx
<div className="max-w-3xl mx-auto px-4 py-8">
  {/* Header: deck name + progress count */}
  {/* Progress bar */}
  {/* Card or SessionComplete or Empty state */}
  {/* Rating buttons (only when flipped) */}
</div>
```
